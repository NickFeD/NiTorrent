# Понятия NiTorrent

Словарь основных понятий торрент-клиента. Описывает язык проекта; наличие термина не означает, что все связанные сценарии уже реализованы.

## Language

**Торрент**:
Отдельная загрузка или раздача, которой пользователь управляет как одной записью в своей коллекции.
_Avoid_: файл торрента, когда речь о самой загрузке.

**Коллекция торрентов**:
Набор добавленных пользователем торрентов, который должен сохраняться между запусками приложения.
_Avoid_: состояние движка как синоним всей коллекции.

**Источник торрента**:
Данные, позволяющие получить описание торрента: файл `.torrent`, его содержимое либо magnet-ссылка.
_Avoid_: скачанные файлы как синоним источника.

**Метаданные торрента**:
Описание содержимого торрента, включая имя, идентифицирующий хеш, состав файлов и их размеры.
_Avoid_: скачанные данные.

**InfoHash**:
Хеш, идентифицирующий содержимое метаданных торрента и используемый для распознавания повторного добавления.
_Avoid_: идентификатор записи в коллекции.

**Предпросмотр торрента**:
Этап перед подтверждением добавления, на котором пользователь видит содержимое и выбирает папку и нужные файлы.
_Avoid_: уже добавленный торрент.

**Выбор файлов**:
Отметка файлов торрента, которые пользователь хочет скачивать.
_Avoid_: приоритет файлов, если речь только о выборе скачивать или пропустить.

**Пользовательское намерение**:
Желаемое пользователем состояние торрента, например продолжать передачу либо оставаться на паузе.
_Avoid_: фактическое состояние передачи как синоним намерения.

**Состояние передачи**:
То, что происходит с торрентом сейчас: получение метаданных, проверка, скачивание, раздача, остановка или ошибка.
_Avoid_: пользовательское намерение.

**Подготовка торрента**:
Приведение торрента в состояние, в котором можно применить актуальное пользовательское намерение и наблюдать реальную передачу.
_Avoid_: открытие страницы торрентов как синоним подготовки.

**Отложенное удаление с данными**:
Принятое решение удалить торрент вместе со скачанными файлами, выполнение которого ещё не завершено.
_Avoid_: завершённое удаление.

**Восстановление сессии**:
Возвращение сохранённых торрентов в рабочую сессию после запуска приложения.
_Avoid_: повторное добавление пользователем.

**Раздача**:
Передача доступных частей торрента другим участникам, в том числе после окончания скачивания.
_Avoid_: завершение как синоним прекращения всякой передачи.

**Удаление из клиента**:
Удаление торрента из пользовательской коллекции с сохранением скачанных файлов.
_Avoid_: удаление данных.

**Удаление с данными**:
Удаление торрента из коллекции вместе с относящимися к нему скачанными файлами.
_Avoid_: удаление из клиента без уточнения режима.
