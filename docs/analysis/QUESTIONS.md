Остальные варианты — материал для выбора, а не утверждённые требования. Отвечать на всё сразу не требуется: достаточно вопроса, относящегося к следующей задаче.

## Как записывать ответ

Для выбранного вопроса достаточно заполнить:

```text
ID вопроса:
Решение владельца:
Пример: пользователь делает ... при условии ...
Ожидаемый результат:
Что делать при ошибке:
Что пока не входит в задачу:
Критерий приёмки:
```

Решение после подтверждения переносится в описание задачи и затронутую спецификацию. Если оно меняет существенный архитектурный выбор, дополнительно сверяется с существующими ADR. Пока ответа нет, варианты из таблицы не становятся поручениями на реализацию.
