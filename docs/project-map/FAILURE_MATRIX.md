# Поведение при ошибках

Сверено 2026-11-27 по исходникам и ранее выполненным проверкам. Матрица различает реализованное поведение и открытый продуктовый вопрос.

| Случай | Текущее поведение / ограничение |
| --- | --- |
| Ошибка общего engine при старте | Один повтор; общая ошибка публикуется независимо от наличия UI-подписчиков. Это не бесконечный перезапуск |
| Ошибка подготовки одного торрента | Запись остаётся с ошибкой, другие продолжаются; локальный Retry учитывает актуальное намерение |
| Отсутствуют metadata старого magnet | Нельзя начать скачивание всех файлов в обход сохранённого выбора; локальная ошибка |
| Ошибка удаления с файлами | Deleted/DeleteFiles остаются до успеха; возможен повтор и продолжение после перезапуска |
| Ошибка чтения статистики | Последние данные + Disconnected; чтение повторяется, пока есть спрос. Это не повтор команд |
| Неподдерживаемые подробности | Unsupported с объяснением; сбор таких данных не запускается |
| Медленный/ошибочный подписчик | Не блокирует других; один последний ожидающий снимок, ошибки обработчика журналируются |
| Две ошибки создания трея | Окно доступно, показывается диалог. Скрытие в недоступный трей не считается успешным |
| Обычная ошибка записи каталога/настроек | Новые данные остаются в памяти для следующей записи; финальный flush сообщает об ошибке. Аварийная потеря последних изменений возможна |
| Повреждённый каталог при старте | Загрузка может завершить запуск host ошибкой; оболочка ошибки запуска остаётся отдельным сценарием. Файл не должен молча заменяться пустым. Полная политика восстановления ещё не определена |
| Ошибка применения настроек | Настройки/Current уже могли измениться; автоматический откат не реализован. UX и гарантия успеха Apply требуют решения |
| Неполное завершение/таймаут | Общий предел ожидания 10 секунд; ложный clean marker не обещается |

Нельзя переносить из старой матрицы гарантии карантина runtime-state, возврата прежних настроек или автоматического ремонта каталога без проверки реализации.
